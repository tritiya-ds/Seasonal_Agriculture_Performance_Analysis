# Seasonal_Agriculture_Performance_Analysis


## AICTE VOIS AICTE Batch 1 (2026–2027)

### Project
Analyze seasonal agricultural performance using the supplied farm dataset.

### Run the project
```bash
pip install -r requirements.txt
jupyter notebook Seasonal_Agriculture_Performance_Analysis.ipynb
```

### Workflow
1. Load and inspect data
2. Audit missing values and duplicates
3. Median-impute missing numeric values for analysis
4. Compare Kharif, Rabi and Zaid
5. Compare crops
6. Analyze irrigation methods
7. Study correlations
8. Run one-way ANOVA on seasonal yield
9. Generate evidence-based recommendations

The notebook is the primary reproducible analysis artifact. The presentation summarizes the findings.

**Caution:** associations in this dataset should not be interpreted as causal effects.
